# Rigorous Single-Cell Skills

Six focused, audit-first skills for careful single-cell research. They complement a scientific agent and do not replace primary-method documentation or biological judgment.

## Included

- `input-audit`: matrix provenance, counts, feature alignment, metadata, and memory-safe loading.
- `donor-level-inference`: donor-aware comparisons, pairing, batch identifiability, and multiplicity.
- `scdemon-validation`: donor-held-out module validation and fair baselines.
- `cross-cohort-replication`: donor overlap, frozen definitions, and missing-state handling.
- `target-evidence`: endpoint-aware evidence for specificity, causality, and modality claims.
- `research-claims`: traceability from claims to figures, code, searches, and execution status.

Original counts are preserved. Donors, not cells, are the biological replicates for condition-level inference. Exploratory findings remain exploratory until independently validated.
